This project contains anonymized dataset which was used in the attached R code to classify National Forest Inventory plots (Korhonen et al., 2024) as old-growth vs. non-old-growth in Finland. Predictor variables contained airborne laser scanning, Sentinel-2, aerial image and auxiliary remote sensing -based variables. Data of this repository was used in the paper titled 'Detection of old-growth forests using airborne laser scanning and other auxiliary data combined with National Forest Inventory field plot data' by Janne Toivonen and Parvez Rana.

Make sure to unzip the model data and have needed R packages loaded before continuing.

Reference:
Korhonen, K. T., Räty, M., Haakana, H., Heikkinen, J., Hotanen, J.-P., Kuronen, M., Pitkänen, J. 2024. Forests of Finland 2019–2023 and their development 1921–2023. Silva Fennica, 58 no. 5 article id 24045. https://doi.org/10.14214/sf.24045
